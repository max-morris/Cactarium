Finding things

Search

The search box at the top of every page, and the search page, match entry names (owner/name), summaries, the thorns and implementations a package provides, and the thorns a stack or a sim builds. Searching CarpetX among stacks lists the stacks one of whose releases builds a CarpetX thorn. Entries whose name matches exactly come first.

Filter by kind: packages, stacks, sims or thorns. A thorn search matches thorn names, implementations and arrangements, and lists each thorn with the package that provides it and that package's latest version containing it. Only public, published versions count.

Thorn pages

Every thorn has a page: /thorns/Arrangement/Thorn, or /thorns/Thorn to match the name in any arrangement (Cactus thorn names are global). It shows:

  • Provided by: the packages that contain the thorn, with the latest version that has it;
  • Built by: the public stacks and sims whose newest release builds it. A thorn a thornlist only checks out (on its !CHECKOUT line) isn't built, so it doesn't count.

Implementations have pages too: /implementations/driver lists the thorns that implement driver.

On an entry's page

  • A package has tabs for its README, its thorns with their CCL facts, its versions, and Used by: the stacks and sims that pin its repo. Its Compatibility box lists its claims and caveats. A track selector appears when it has several tracks, and the cactup add command is ready to copy.
  • A stack shows its frozen thornlist, the pin of every repo, what changed since the previous release, what it extends, and Used as a base by: the stacks that extend it.
  • A sim has tabs for its parfile, thornlist, pins, inputs, run hints and versions, and the cactup import command.

In a pin table, a repo that a registered package uses links to that package (to the exact version, when the pinned commit is a version). Any other repo is marked unregistered source and links to a page listing everything on the Cactarium that pins it.

Forks and the compare page

A package that declares [[fork-of]] appears under Forks on its upstream's page, and the fork's page links back. Compare opens /compare?a=owner/upstream&b=owner/fork: the two packages side by side, with their newest versions, tracks, repos, contacts and claims, and which thorns only one of them has and which both have. Any two packages can be compared this way.

Saves

Signed in, the heart button on an entry's page saves it; pressing it again removes the save. Saved entries are listed on your dashboard. The number of saves is public: it shows on every entry's page, comes back from the API as hearts, and orders the stacks and sims on thorn pages.
