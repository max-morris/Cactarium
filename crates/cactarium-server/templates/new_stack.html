Publish a stack

A stack is a versioned thornlist. Publish it from a repo, where each version tag becomes a release, or upload its definition here and name the version yourself. Either way, every release pins each repo to a commit and never changes. One stack uses one way, not both.

From a repo

Commit cactarium-stack.toml (and its thornlist) at the repo root, listing your name or organization in owners, and push a version tag such as v1.0.0. Then register the repo; later tags become new releases by themselves. See the stack reference.
