Publish a stack

A stack is a versioned thornlist. Upload its definition here and name the version yourself, or publish it from a repo, where each release tag becomes a release. Either way, every release pins each repo to a commit and never changes. One stack uses one way, not both.

From a repo, where each release tag becomes a release: commit cactarium-stack.toml (and its thornlist) at the repo root, listing your name or organization in owners, push a release tag such as v1.0.0, then register the repo. See the stack reference.

By upload

Give the definition directly. The Cactarium merges its sources, pins every repo (its pins first, then each branch's current commit) and freezes the result as the version you name.
