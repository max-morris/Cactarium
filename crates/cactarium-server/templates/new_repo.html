Register a repo

Your code stays in your repo. The Cactarium reads it at every release tag and freezes the commit the tag names. Packages, stacks and sims are all registered here.

  1. Commit cactarium.toml (a package), cactarium-stack.toml (a stack) and/or cactarium-sim.toml (sims: it names the .sim file, or several in [sim.files]) at the repo root, each with owners = ["{% if let Some(u) = ctx.user %}{{ u.username }}{% endif %}"] (or the organization you publish under). Only someone who can push to the repo can put that name there; that is the proof you control it. Each manifest becomes its own entry, named by its name.
  2. Tag a release: v1.0.0, or on a track, mixed-precision/v1.0.0, or whatever the manifest's tag-pattern says. Without patterns, one tag releases every kind the repo carries; see how tags become versions.
  3. Paste the repo's https URL below and preview: the Cactarium finds each manifest's newest release among the repo's tags and shows what it would register, writing nothing. Then confirm the entries you want. A repo that already has entries gets only the missing ones.
